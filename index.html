Напоминания iPhone

Как настроить команду (один раз)
  1. Откройте приложение «Команды», нажмите «+».
  2. Назовите команду точно так же, как в поле выше (по умолчанию TaskToReminder).
  3. Добавьте действие «Получить словарь из входных данных». Входные данные: «Входные данные команды».
  4. Добавьте три действия «Получить значение для ключа» из этого словаря: ключи title, notes, due.
  5. Добавьте «Если»: значение due «имеет любое значение».
  6. Внутри «Если»: «Получить даты из входных данных» (вход: значение due), затем «Добавить новое напоминание»: текст — значение title, заметки — значение notes, включите «Предупредить» и укажите полученную дату.
  7. В блоке «Иначе»: «Добавить новое напоминание» с title и notes, без даты.
  8. При первом запуске разрешите доступ к Напоминаниям и откройте ссылку в «Командах».

Приложение не видит, сработала ли команда, поэтому отметка «создано» ставится при отправке. Если что-то пошло не так, отметку можно убрать.

Резервная копия

Задачи хранятся только на этом телефоне. Время от времени сохраняйте копию в «Файлы» или iCloud.

Импорт из Заметок

  1. В Заметках откройте заметку, нажмите на текст и выберите «Выбрать все» → «Скопировать».
  2. Вставьте сюда: долгое нажатие в поле → «Вставить».
  3. Проверьте разбор ниже. Первая строка заметки (её название) по умолчанию пропускается. Если строка распознана неверно, нажмите на неё, чтобы сменить тип.
